- الصور **المركّبة على التذاكر**: ملفاتها مربوطة في `PLAYER_MAP` و`UCL_BASE_PLAYERS` داخل `website/src/components/LeagueTicketCard.tsx` (بادئة الاسم = البطولة: `eng-` الإنجليزي، `egy-` المصري، `sau-` السعودي… إلخ).
