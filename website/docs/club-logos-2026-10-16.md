# استبدال الرموز الحرفية بشعارات الأندية

بناءً على طلب المالك، استُبدلت الرموز الطباعية بشعارات الأندية الثمانية في بطاقات الموسم وصفحات المباريات الأربع: روما، ريال مدريد، مانشستر سيتي، باريس سان جيرمان، أتلتيكو مدريد، مانشستر يونايتد، جالاتا سراي، برشلونة. لا صور مباريات مضافة إلى الكروت. صفحات المتابعة التي لا تعرض صور أندية بقيت دون صور زائدة.

## المصادر والأصول

- المصدر: `https://github.com/JoseArroyave/football-logos`، المراجعة المثبتة `1b0a81b0a5538131a2867b3c28a19a459a51d987`.
- ملفات SVG الأصلية تحت `src/assets/club-logos/`، مع manifest يسجل رابط كل ملف وبصمته Git blob SHA، ونص LICENSE المنشور من المستودع.
- المستودع يوزع الملفات تحت MIT ويذكر استخدامها الشخصي والتجاري. هذا توثيق لترخيص توزيع المستودع، لا ضمان مستقل لحقوق العلامات التجارية أو تصريح من الأندية أو إثبات رعاية منها. لم يُعدّل نص إخلاء المسؤولية أو DMCA أو التذييل القانوني.
- إشعار المصدر والترخيص محفوظ أيضاً في `public/_assets/club-logos-notices.txt` ويُنشر مع الأصول.
- العرض محلي بصيغة WebP شفافة 280×280. أسماء الملفات الجديدة تنتهي بـ `-club-badge.webp` لتفادي استمرار ظهور الرموز القديمة من ذاكرة المتصفح. بقيت أبعاد العرض وlazy loading للكروت والنص البديل الوصفي، وأصبح الأخير «شعار [الفريق]».
- لم تُضف صور عن بُعد أو تضمينات أو تبعيات أو متتبعات. لم تتغير بيانات المباريات أو SEO أو مسارات الصفحات أو الأسعار.

## توليد الأصول

من داخل website:

```sh
node scripts/generate-analysis-badges.mjs
npm run build
```

احتُفظ باسم أمر التوليد للتوافق مع التوثيق السابق، لكنه الآن يقرأ الشعارات المثبتة، لا ملفات الرموز الحرفية. يستخدم Playwright/Chromium وImageMagick القائمين؛ تُمنع الاتصالات الخارجية أثناء التصيير، وتُرفض ملفات SVG ذات المحتوى التنفيذي أو المراجع الخارجية. PNG الوسيطة مؤقتة خارج Git وتحذف بعد التحويل.

## المصدر القابل للتحرير

- قوالب التقارير الجديدة: `src/pages/analysis/`؛ تقرير أتلتيكو القديم: `legacy/manchester-united-atletico/`.
- أسماء صور الكروت: `src/content/match-analysis.json`؛ النصوص البديلة في `scripts/render-match-analysis.mjs`.
- استُبدلت ملاحظات وصف الرموز الحرفية السابقة بملاحظة تعريفية مطابقة للأصول الجديدة. لم يُحرر HTML الجذر يدوياً؛ النسخ المنشورة من البناء.

## التحقق

أضيف اختباران للتحقق من المصادر المثبتة والترخيص وبصمات الملفات وسلامة SVG، ومن استخدام الشعارات المحلية الستة عشر في الكروت والتقارير دون عودة الصور أو الرموز الحرفية. نتائج البوابات:

- `npm run typecheck`: ناجح.
- `npm run build`: ناجح، وأعيد بعد اعتماد أسماء صور جديدة لتفادي الكاش.
- `npm run test`: **324/324 ناجحة، صفر فشل وصفر تجاوز**، بما فيها اختبارا أصول الشعارات الجديدان.
- `CI=1 npm run test:ui`: **170/170 ناجحة** في التشغيل الكامل، دون فشل أو إعادة محاولة. CI يستخدم إعداد إعادة المحاولة القائم في المشروع؛ لم تُغيّر الاختبارات أو مهلها.
- تأكيد الواجهة بعد تحديث أسماء الصور وإعادة البناء: **14/14 ناجحة** تشمل البطاقات والروابط والتقرير الجديد وعروض 320–1440 بكسل.
- فحوص الحفظ: 43 HTML متتبعاً/42 GA4 سابقاً، لا تغيير في GA4 أو عدد محملات أدسنس أو النص القانوني. لا فروق في PHP أو admin-dashboard أو channels.json أو ads.txt أو lockfile؛ `git diff --check` نظيف.
- روجعت لقطة الكروت الأربع بصرياً، والشعارات الثمانية واضحة. لا صور مباريات أو رسوم حرفية بديلة معروضة.
- سجلات التحقق المحلية: `/home/user/compliance-audit/club-logos-{typecheck,build,tests,ui}.log`؛ فحص واجهة إضافي بعد تحديث أسماء ملفات الصور في `club-logos-final-ui.log`.

لم يحدث commit أو push أو إنشاء PR أو دمج أو نشر إنتاجي.

## جسر مؤقت: شعارات المتصدّرين من مصدر بطاقات المباريات الحيّة (2026-10-19)

بطلب المالك («موقتاً»)، صار البانر العلوي لكروت «صفحات البطولات» يأخذ شعار المتصدّر من **نفس مصدر شعارات بطاقات المباريات الحيّة** في صفحة المواعيد: مضيف ESPN CDN بالمسار الثابت الذي يردده المصدر في حقل `team.logo`:

```
https://a.espncdn.com/i/teamlogos/soccer/500/<ESPN teamId>.png
```

- العنوان يُركَّب من `teamId` الموجود أصلاً في لقطة الترتيب، **بلا أي طلب بيانات جديد** (لا standings ولا scoreboard) وبلا تخزين صور إضافية.
- لا يُطبَّق إلا على بطولة مصدرها `ESPN` وبمعرّف رقمي. الدوري المصري مصدره Highlightly ومعرّفه ليس معرّف ESPN، فيبقى على الشعار المحلي المعتمد (بيراميدز).
- سلسلة النزول عند الفشل: صورة المصدر → الشعار المحلي المعتمد → بديل الأحرف. لا صورة مكسورة، وارتفاع البانر 104px لا يتغيّر.
- المكتبة المحلية لم تُحذف: هي البديل الفوري، وتبقى مستخدمة في بطاقات المعدلات وجداول الترتيب كما هي.
- للرجوع: تغيير `LEADER_CREST_SOURCE` في `website/src/lib/leader-logo.mjs` إلى `'local'` يعيد البانر إلى المكتبة المحلية وحدها بلا أي تعديل آخر.
- التحقق: اختبار وحدة لعقد الجسر (يرفض أي مضيف أو معرّف غير مطابق)، واختبار الواجهة يحاكي المضيف محلياً ويتحقق من الشعارات الثمانية ومن سلسلة النزول ومن ارتفاع البانر. لا يمكن فحص `a.espncdn.com` مباشرةً من بيئة التطوير (الشبكة محجوبة)، والعنوان هو نفسه الوارد في استجابات ESPN الرسمية (`team.logo`).

## تحديث الجسر المؤقت: شعار الدوري المصري من Highlightly (2026-10-19)

بطلب المالك، صار شعار متصدّر الدوري المصري يأتي من **مزوّد ترتيب البطولة نفسه (Highlightly)** بدل الاكتفاء بالمكتبة المحلية:

```
https://highlightly.net/soccer/images/teams/<Highlightly teamId>.png
```

- المسار هو نمط صور الفرق المنشور في وثائق المزوّد، والصور لا تتطلب مفتاح API (الترويسات مطلوبة لطلبات البيانات فقط). تحقّقنا من وجود شعار الفريق `882420` (الأسيوطي/بيراميدز) بطلب مباشر للملف: الملف موجود (استجابة غير-404)، ومعرّف غير موجود يعيد 404 — فلا يُعرض «شعار» على مسار وهمي.
- القرار صار في `providerTeamLogo()` بوحدة `leader-logo.mjs`: يفضّل حقلاً صريحاً معتمداً إن أرسله المصدر، ثم مضيف ESPN لبطولات ESPN، ثم مضيف Highlightly لبطولات Highlightly، وإلا فلا صورة.
- مصدر الشعار ظاهر في السمة `data-crest-source` (`espn` / `highlightly` / `local`) للمراجعة والفحص، بلا أثر بصري.
- سلسلة النزول كما هي: مزوّد البطولة → الشعار المحلي → بديل الأحرف، وارتفاع البانر 104px ثابت.
- حدود: لا مفتاح API ولا طلب بيانات في المتصفح؛ العنوان يُركَّب من `teamId` الموجود في اللقطة. ومضيفان فقط مسموحان (`a.espncdn.com` و`highlightly.net`)، وأي عنوان آخر يُرفض ويُستبدل بالمحلي.
- للرجوع: `LEADER_CREST_SOURCE = 'local'`.
