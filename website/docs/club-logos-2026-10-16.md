# استبدال الرموز الحرفية بشعارات الأندية

بناءً على طلب المالك، استُبدلت الرموز الطباعية بشعارات الأندية الثمانية في بطاقات الموسم وصفحات المباريات الأربع: روما، ريال مدريد، مانشستر سيتي، باريس سان جيرمان، أتلتيكو مدريد، مانشستر يونايتد، جالاتا سراي، برشلونة. لا صور مباريات مضافة إلى الكروت. صفحات المتابعة التي لا تعرض صور أندية بقيت دون صور زائدة.

## المصادر والأصول

- المصدر: `https://github.com/JoseArroyave/football-logos`، المراجعة المثبتة `1b0a81b0a5538131a2867b3c28a19a459a51d987`.
- ملفات SVG الأصلية تحت `src/assets/club-logos/`، مع manifest يسجل رابط كل ملف وبصمته Git blob SHA، ونص LICENSE المنشور من المستودع.
- المستودع يوزع الملفات تحت MIT ويذكر استخدامها الشخصي والتجاري. هذا توثيق لترخيص توزيع المستودع، لا ضمان مستقل لحقوق العلامات التجارية أو تصريح من الأندية أو إثبات رعاية منها. لم يُعدّل نص إخلاء المسؤولية أو DMCA أو التذييل القانوني.
- إشعار المصدر والترخيص محفوظ أيضاً في `public/_assets/club-logos-notices.txt` ويُنشر مع الأصول.
- العرض محلي بصيغة WebP شفافة 280×280. أسماء الملفات الجديدة تنتهي بـ `-club-badge.webp` لتفادي استمرار ظهور الرموز القديمة من ذاكرة المتصفح. بقيت أبعاد العرض وlazy loading للكروت والنص البديل الوصفي، وأصبح الأخير «شعار [الفريق]».
- لم تُضف صور عن بُعد أو تضمينات أو تبعيات أو متتبعات. لم تتغير بيانات المباريات أو SEO أو مسارات الصفحات أو الأسعار.

## توليد الأصول

من داخل website:

```sh
node scripts/generate-analysis-badges.mjs
npm run build
```

احتُفظ باسم أمر التوليد للتوافق مع التوثيق السابق، لكنه الآن يقرأ الشعارات المثبتة، لا ملفات الرموز الحرفية. يستخدم Playwright/Chromium وImageMagick القائمين؛ تُمنع الاتصالات الخارجية أثناء التصيير، وتُرفض ملفات SVG ذات المحتوى التنفيذي أو المراجع الخارجية. PNG الوسيطة مؤقتة خارج Git وتحذف بعد التحويل.

## المصدر القابل للتحرير

- قوالب التقارير الجديدة: `src/pages/analysis/`؛ تقرير أتلتيكو القديم: `legacy/manchester-united-atletico/`.
- أسماء صور الكروت: `src/content/match-analysis.json`؛ النصوص البديلة في `scripts/render-match-analysis.mjs`.
- استُبدلت ملاحظات وصف الرموز الحرفية السابقة بملاحظة تعريفية مطابقة للأصول الجديدة. لم يُحرر HTML الجذر يدوياً؛ النسخ المنشورة من البناء.
