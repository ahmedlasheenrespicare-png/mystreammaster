# مقال «أفضل سيرفر IPTV في مصر» — دليل الصيانة

**الصفحة:** `/blog/افضل-سيرفر-iptv-في-مصر/` · **تاريخ النشر:** 2026-10-23
**الكلمة المستهدفة:** «أفضل سيرفر IPTV في مصر» (قصد: comparison)

## إدخال الأسعار (الخطوة الوحيدة المطلوبة منك)

كل أسعار السوق المصري تُكتب في ملف واحد: `website/src/content/egypt-pricing.ts`

```ts
{
  code: "nova",
  name: "نوفا (Nova)",
  bestFor: "المباريات وذروة المساء",
  devices: "حتى 3 أجهزة",
  prices: { "3": null, "6": null, "12": null }, // ← ضع الأرقام بالجنيه المصري هنا
}
```

- القيمة = **إجمالي سعر المدة** بالجنيه المصري (لا سعر شهري). الصفحة تحسب
  المتوسط الشهري تلقائياً أسفل كل سعر.
- اترك `null` لأي مدة غير متاحة؛ تظهر الخانة «باتفاق» وليس صفراً.
- حدّث `EGYPT_PRICING_UPDATED` بتاريخ الأسعار (يظهر تحت الجدول)، مثال: `"2026-10-25"`.
- الأسعار هنا **عرض مصر فقط** ولا تتغيّر بها أسعار المتجر في `src/data.ts`
  (التي تبقى محسوبة من الدولار لكل الصفحات).
- بعد التعديل: `npm run build` ثم `npm run preview`. لا تُحرّر HTML المولّد.

### سلوك القفل (مقصود)

قسم «أسعار الاشتراك في مصر بالجنيه المصري» **لا يُنشر قبل وصول الأرقام**:
لا عنوان فارغ ولا رقم «0». الحارس `scripts/test-egypt-pricing.mjs` يفشل إن ظهر
العنوان بلا جدول، أو اختلف رقم معروض عن رقم مكتوب في الملف، أو ظهر `NaN`.
