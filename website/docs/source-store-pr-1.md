# وصف PR 1 — المكتبة المشتركة وscoreboard

## النطاق

`lib/source_store.php` و`lib/espn_source.php` و`lib/sportsdb_source.php` و`scoreboard.php` وفحص عقد matches.
لا إضافة بطولات أو تبديل مصادر. ملفات ESPN لكل بطولة/يوم UTC، وجلب الأيام المستحقة فقط عبر curl_multi كما كان. نقل تطبيع TheSportsDB والبحث الثنائي والسياسة إلى المكتبة، مع الاحتفاظ بالجولات المجمدة القديمة عبر ترقية سجل تحت القفل.

## سلامة البيانات

Schema موحد، كتابة ذرية، قفل الوحدة حتى اكتمال كتابة النجاح أو الفشل؛ تأجيل الفشل حتى بلا نسخة أو مع احتياط منتهي. حماية 500 ESPN و15 TheSportsDB. STALE لا يُكتب طازجاً ولا يمدد عمر آخر نجاح بكاش الرد المجمع. كاش الرد 45 وحد الاحتياط الحالي 600 لا يتغيران؛ غير الجارية في TheSportsDB تحتفظ بسياسة PR #54.

**تغيير إعداد لازم للتوافق مع شرط عدم وجود مفاتيح بالكود:** إزالة fallback المفتاح العام المكتوب سابقاً. SM_SPORTSDB_KEY من البيئة أو ملف الخادم الخاص فقط؛ الغياب يعطي UPSTREAM_KEY_MISSING. لا اشتراك مدفوع أو مفتاح جديد اختير تلقائياً.

## القيود الواجب إبقاؤها في وصف PR

- مباراة مؤجلة خارج نطاق وحدتها الأصلية قد تغيب في يومها الجديد.
- مرور يومين والتجميد لا يضمنان ألا يضيف المصدر مباريات لاحقاً.
- الجولة/اليوم الفارغ مخزّن ساعة؛ قد يتأخر ظهور الجدول حتى ساعة.
