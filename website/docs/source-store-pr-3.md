# وصف PR 3 — الترتيب والاختبار المتكرر

يعتمد على PR 1، ويُختبر مع PR 2. النطاق: `standings.php` ونسخة website/public، ونسخة المكتبة المشتركة اللازمة لبناء Vite، وحزمة QA وCI.

## الموافقة والنطاق

صاحب المشروع وافق في هذه الجلسة على 120 ثانية عند وجود دليل مباراة جارية اليوم في الملفات المشتركة، و900 في غير ذلك. لا جلب حالة إضافي، ولا توسعة قوائم أو تبديل ESPN/Highlightly. المفتاح المصري ومساره وترويساته السرية كما هي.

- تحقق العدد كان موجوداً بالفعل ويرفض الجدول الناقص؛ الرمز الآن UPSTREAM_INCOMPLETE بدلاً من UPSTREAM_SCHEMA_CHANGED العام، مع بقاء شروط القبول كما هي.
- كل فشل يكتب checked_at/error، والمحاولة التالية بعد 60 ثانية، حتى مع غياب النسخة أو تجاوز عمرها. آخر نجاح/حقوله لا يتغير عند الفشل. حد الاحتياط 86400 ثابت.
- لا تجميد نهائي لجدول موسم دون دليل من المصدر على انتهاء الموسم؛ اكتمال مباريات اليوم لا يكفي. هذا قيد واضح، وليس ادعاء بتجميد كل الجداول.
- ksa.1 لا يُضاف للمباريات ولا يُطابق تلقائياً مع sau.1؛ عند غياب دليل مطابق تطبق 900 ثانية.
- القواعد الرقمية وعدد الصفوف والحقول الحالية لم تتغير؛ standings.mjs لا يحتاج تعديلاً. نسختا PHP والمكتبة متطابقتان بفحص صريح يمنع إلغاء التغيير أثناء النشر.

## خطة الاختبار والنتائج المحلية

- before/after على الاستجابات الخام المولدة من **اللقطة نفسها للبطولات الثماني**، بمقارنة قيم وحقول الترتيب حرفياً، لا مقارنة شكل اصطناعي فقط.
- `npm test --prefix tests/source-store`: **242 فحصاً ناجحاً على PHP 8.3.30** + HTTP/نسخ النشر؛ كل مزوّد، العدد الناقص، stale/expiry/backoff/no-copy، 429/timeout/network/JSON، ردود خالية من المفاتيح، وسياسة 120/900 واختصار النسخة السابقة عند ظهور مباراة جارية.
- `node --test website/scripts/test-standings.mjs`: **18/18** بما فيها تشغيل PHP الحقيقي عبر WASM.
- `npm test`: **374/374 دون skipped**، وtypecheck وbuild:client ناجحان.
- QA له package-lock مستقل، وCI يجلب تاريخ git لمقارنة baseline c7eb4f3، ويثبت حزمة الاختبار ويشغلها؛ tests/** مستبعدة من FTP الإنتاجي.
- الفحوص ليست اختبار اتصال فعلي بالمزوّدين أو اختبار PHP-FPM متعدد العمال على Hostinger. نتائج الخادم تبقى مطلوبة بعد الدمج.

## القيود الواجب إبقاؤها في وصف PR

- مباراة مؤجلة خارج نطاق وحدتها الأصلية قد تغيب في يومها الجديد.
- مرور يومين والتجميد لا يضمنان ألا يضيف المصدر مباريات لاحقاً.
- الجولة/اليوم الفارغ مخزّن ساعة؛ قد يتأخر ظهور الجدول حتى ساعة.
- TheSportsDB المجاني للتطوير، ESPN غير موثق، وHighlightly له شروطه؛ مراجعة الشروط والخطة مسؤولية المالك قبل الاعتماد الدائم.
- تحقق Hostinger وقياسات الساعة الأولى **غير منفذين**؛ تُضاف النتائج الفعلية بعد النشر وفق [قائمة التشغيل](source-store-rollout.md)، وليس بيانات اختبار وهمية.
