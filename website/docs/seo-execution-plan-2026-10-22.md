## 0) المبدأ الحاكم للخطة

> **لا صفحات جديدة حتى تصبح الصفحات الحالية جديرة بالفهرسة.**

الموقع لا يعاني نقصاً في عدد الصفحات (83 صفحة قابلة للفهرسة كافية جداً لموقع خدمي)، بل في أن **24 منها رقيقة، و18 منها لا تحمل كلمتها**. إضافة صفحات جديدة الآن تُكرّر النمط الذي تعاقب عليه تحديثات Google المواقع الوسيطة.

**ثلاث قواعد تنفيذية:**
1. كل PR يفعل شيئاً واحداً قابلاً للقياس — لا تخلط النصوص مع الصور مع البنية.
2. لا تغيير في `slug` أو `canonical` بلا خطة 301 متزامنة.
3. لا يُدمج PR قبل بناء نظيف محلياً (`npm run build`) + `SEO_STRICT=1`.
