# وصف PR 2 — مركز المباراة

يعتمد على PR 1. النطاق: `match-center.php` و`lib/event_summary.php` واختبارات عقد المركز.

- جدول اليوم يقرأ نفس وحدة ESPN التي يستخدمها scoreboard؛ لا كاش يوم مستقل ولا طلب ثانٍ لنفس البطولة/اليوم.
- summary ملف لكل بطولة/حدث، يتبع الحالة، والجارية 60 ثانية والمنتهية تجمد بعد يومين. لا تجميد لبيانات ناقصة التاريخ ولا ربط summary بمعرّف حدث آخر.
- كاش الرد 45 ثانية قائم؛ الكتابة ذرية تحت قفل للرد. احتياط المصدر حتى 600 من آخر نجاح، لا من وقت كتابة الرد.
- فشل summary لا يمحو نتيجة صحيحة من جدول اليوم، لكن الرد STALE مع تشخيص ولا يدخل الكاش الطازج. فشل الجدول بلا نسخة صالحة يرجع خطأ.
- رموز HTTP المعروفة في المركز تبقى UPSTREAM_HTTP_xxx (ومنها UPSTREAM_HTTP_429)، مع UPSTREAM_UNREACHABLE للأخطاء الشبكية المعتادة؛ رموز JSON/truncation/timeout صريحة. شكل الحمولة وقائمة الربط لم يتغيرا.

## القيود الواجب إبقاؤها في وصف PR

- مباراة مؤجلة خارج نطاق وحدتها الأصلية قد تغيب في يومها الجديد.
- مرور يومين والتجميد لا يضمنان ألا يضيف المصدر مباريات لاحقاً.
- الجولة/اليوم الفارغ مخزّن ساعة؛ قد يتأخر ظهور الجدول حتى ساعة.
- TheSportsDB المجاني للتطوير، ESPN غير موثق، وHighlightly له شروطه؛ مراجعة الشروط والخطة مسؤولية المالك قبل الاعتماد الدائم.
- تحقق Hostinger وقياسات الساعة الأولى **غير منفذين**؛ تُضاف النتائج الفعلية بعد النشر وفق [قائمة التشغيل](source-store-rollout.md)، وليس بيانات اختبار وهمية.
